# 独立 SCPI TCP 虚拟电源

## 目标

虚拟电源独立运行并监听本机 TCP。测试软件发送实际 SCPI 文本，虚拟电源解析指令、保存仪器状态并返回查询结果。软件通过通信驱动访问虚拟电源，不能直接访问模拟器的内存状态。

同一台仪器的手动测试与自动步骤共用设备访问服务。自动测试运行期间暂停手动操作和轮询；自动步骤执行到读取操作时才发起查询。

## 当前状态

- 当前 `SimulatedChannelRuntimeCoordinator` 使用进程内字典读写；它没有发送 SCPI。
- 当前 `OpenTapSignalSteps` 也读取、修改 Host 自身的 `SimulationValues`。现有手动协调器与自动执行器并未访问同一台外部仪器。
- PSU-S、PSU-V 等名称是演示配置，不对应已核实的艾德克斯型号或指令集。
- 已加入独立项目 `tools/TestStation.VirtualPowerSupply`，默认监听 `127.0.0.1:5025`。
- 已加入 TCP SCPI 会话、公共 SCPI 电源后端和自动执行器的设备访问消息；手动页面与 OpenTAP 通道步骤可以访问同一个 TCP 虚拟电源。
- 连接断开、超时、设备错误会返回到手动状态或自动步骤，而不是悄悄读取进程内的旧值。

## 通信路径

```text
手动面板 ───────────────┐
                       ├→ 统一设备访问服务 → 型号对应的 SCPI 驱动 → 通信适配器
OpenTAP Host → 进程通信 ┘                                           │
                                                    TCP → 独立虚拟电源
                                                    USB/RS232 → 实体电源
```

OpenTAP Host 运行在独立进程中，需要通过进程通信访问统一设备服务。实施时必须同时改造自动步骤的通道读写，不能只改手动页面。

设备服务负责设备连接、串行化查询、手动轮询和自动占用；SCPI 驱动负责具体型号的命令映射、解析及设备错误；通信适配器负责传输字节。

同型号、同指令版本的虚拟仪器和实体仪器应复用 SCPI 驱动。替换 TCP、RS232、USBTMC/VISA 等通信适配器后，可保留面板和自动步骤。USB 方口仅说明连接器外形，实际设备使用 USBTMC、虚拟串口还是厂商接口，需查对应型号手册。

## 虚拟仪器的必要行为

- 绑定本机地址，主程序配置主机和端口后连接。
- 查询返回数据；普通设置指令通常不返回内容。具体规则跟随型号手册，不能给所有写指令额外增加 ACK。
- 正确处理 TCP 分包、粘包和一条连接中的连续命令；消息结束符按型号配置。
- 每个连接的查询必须串行发送和接收，避免手动轮询与操作读错响应。
- 查询超时后关闭或明确清理当前会话，防止迟到响应被下一条查询消费。
- 输出开关、设定值、测量值、负载、限流和保护为有状态行为，不能只返回固定数字。
- 未定义命令、参数超范围等按型号维护错误队列；不随意向响应流插入自定义错误文本。
- 提供带时间戳的原始收发记录，以及延迟、断线等故障注入。

## 当前公共 SCPI 子集

第一版不声称对应某个具体 ITECH 型号，使用公开、跨厂商常见的 SCPI/IEEE 488.2 命令：

```text
*IDN?          *RST           *CLS
*ESR?          *ESE <mask>    *SRE <mask>
*STB?          *OPC?          *WAI
SYST:ERR?      SYST:ERR:COUNT
SYST:REM       SYST:LOC
SOUR:VOLT <v>  SOUR:VOLT?     SOUR:CURR <a>  SOUR:CURR?
OUTP ON/OFF    OUTP?          MEAS:VOLT?     MEAS:CURR?     MEAS:POW?
```

也接受常见的短写法，例如 `VOLT`、`CURR`、`MEAS:VOLT?` 和 `OUTP?`。普通设置指令不返回 ACK；查询返回一行 ASCII 文本并以 LF 结束。虚拟负载默认是 10 Ω，输出打开后根据设定值计算 CV/CC 和测量值，电压默认上限 60 V、电流默认上限 10 A。

启动虚拟电源：

```text
启动虚拟电源.cmd
```

也可以指定参数：

```text
启动虚拟电源.cmd --port 5025 --max-voltage 60 --max-current 10 --load-ohms 10
```

收发记录默认写入 `tools/TestStation.VirtualPowerSupply/logs/scpi-traffic.log`。软件手动页面的 SCPI 电源面板可以修改主机和端口并点击“连接”。自动运行时，OpenTAP Host 通过主程序的 JSON-lines 通道请求同一个设备服务；每个设置或读取步骤才会发起对应 SCPI 通信，手动轮询在自动占用期间暂停。

第一版可采用确定性的电阻负载模型：输出关闭时测量为零；输出打开时根据设定电压、限流和负载计算 CV/CC 状态及测量值。具体额定值和保护行为必须来自已核实的型号资料。
