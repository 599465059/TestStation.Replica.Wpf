# 手动工区与变量布局优化

日期：2026-11-02。

## 使用方式

- 手动测试不再自动创建全部已安装家族的页面。先在硬件配置中创建设备实例，然后用顶部“添加设备界面”搜索并勾选实例。
- 顶部分组下拉框选择当前测试场景。“分组管理”支持新建、重命名及删除；删除只移除该组面板，不删除设备或断开连接。最后一组删除时清空面板并保留分组。
- 每组最多四个面板，批量添加超过四个时自动建立下一组。支持标签、平铺、双栏、四宫格和层叠；分组选择不增加第二层标签页。
- 双栏优先保留面板高度，内容过多时滚动；四宫格在可用区域内布置两行两列。面板具有最小尺寸，窄窗口通过滚动查看，不把设备控件压成窄条。
- “已打开设备”菜单按组定位设备。再次进入已访问分组复用页面；未访问的分组只保留设备引用，不创建控件。
- 变量表格随面板可用高度伸展，编辑区位于底部：名称一行、类型与作用域并排一行、默认值一行。操作按钮使用公共紧凑样式，引用说明放在提示中。
- 变量编辑区可以折叠，并可拖动分隔线调整高度；保留原右键菜单、图标和作用域颜色。变量输入框保持可读高度，不缩小字体。

## 边界与存储

Application 定义 ManualPanelLayout / ManualPanelGroup / ManualPanelReference 和存储接口。Infrastructure 的 ManualPanelLayoutRepository 保存版本为 1 的布局，使用临时文件加原子替换。文件位于工程 layouts/manual/device-panels.json，保存组名、设备引用、显示模式和当前选择，不保存连接对象或另一份通信参数。

App 的 ManualPanelWorkspaceViewModel 管理分组和设备选择，ManualTestView 只适配已发布的 MdiWorkspace。分组切换从视觉树移除旧表面，触发设备页面 Unloaded 并取消轮询；关闭页面释放 ViewModel 的订阅，设备会话仍由统一连接服务管理。自动执行的互斥与会话复用机制沿用原实现。

ITECH、HIOKI 和参考设备面板按指定实例创建，隐藏实例增删入口并固定设备选择。实例删除后不回退到其他设备。禁用家族时释放所有已创建面板，保留布局引用；恢复启用时仅重建当前组。布局加载错误明确显示，禁止用空布局覆盖原文件。保存失败保留待保存状态，切换工程前再次保存并拒绝丢弃失败的变更。

页面标题随设备重命名更新。重排面板时抑制临时激活通知，避免调整尺寸时反复写布局文件。设备候选目录在目录或家族变化时刷新缓存，不在每次布局时重复扫描全部家族。

当前保存的是显示模式和面板引用；窗口自由拖动后的精确像素位置不持久化，恢复时按所选模式重新排布。

## 设备操作面板紧凑化（2026-11-03）

- ITECH 电源将测量电压、电流并排显示；输出设定、应用设定、读取一次和输出开关集中在下方。保护、扩展通道及通信记录按需展开。
- HIOKI 保留测量表格，限制默认高度并在表格内部滚动，不再为整个页面预留大块固定空间。
- 参考设备在手动工区使用逐通道操作行，名称与读数同行，输入和读写按钮紧邻；家族管理页面仍保留完整通道表格。
- 三类面板统一紧凑标题、连接状态和连接按钮。设备/连接配置默认折叠；无设备时自动展开。固定实例面板继续隐藏实例增删和切换入口。
- 使用共享业务布局样式和现有控件模板，正常输入高度不变。外层面板按滚动容器可用宽度测量，宽表格在内部滚动；小于最小面板宽度时保留外层滚动。
- 修正 ITECH/HIOKI 的资源编辑和新增按钮命令名称，使其实际绑定到 ViewModel 生成的命令。

定向布局入口 `--ui-layout` 使用真实三类 View/ViewModel 检查四面板布局、约 480 像素可用宽度、配置折叠/展开、空状态、命令绑定及输入高度。浅色/深色及青色强调色截图位于 `artifacts/workspace-layout/compact-panels-*.png`。截图读数由验收夹具注入，仅用于布局检查，没有连接设备或执行硬件读写。
