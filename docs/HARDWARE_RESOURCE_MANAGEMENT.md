# 硬件资源管理

当前硬件配置页面由 `DeviceManagementView` 承载，入口是“硬件配置”，页面内分为“通信资源”和“设备实例”两个标签。

## 资源生命周期

1. 在“通信资源”中点击“新建”，选择 TCP、串口、CAN 或 VISA，并填写该传输类型的参数。
2. 保存前在编辑对话框中校验端点、超时、终止符、串口线路模式和 CAN 波特率。
3. 在“设备实例”中新建设备，选择设备家族、型号和通信资源；新实例不会自动连接。
4. 设备连接时由 `ResourceManager` 申请租约并创建传输会话。TCP、串口和 VISA 独占资源，CAN 默认共享总线。
5. 设备断开、诊断关闭、自动测试结束或连接失败时释放租约。

资源表格的占用列显示当前租约数量，悬停可查看占用者和各自的租约计数。被占用资源不能编辑或删除；被设备绑定但未连接的资源可以编辑，删除前必须先解除绑定。

## 传输参数

- 串口使用同一个传输实现，通过 RS232、RS422、RS485 模式和波特率、数据位、校验位、停止位、流控、半双工参数区分线路配置。
- CAN 资源保存后端、通道、仲裁波特率、CAN FD 数据波特率和只听模式。CAN 节点地址属于设备或协议配置。
- VISA 资源可以保存 VISA 资源名，但当前没有真实 VISA 后端时禁止连接，连接错误会明确提示“VISA 后端未安装”。

工程资源保存于 `resources/resources.json`，使用版本字段和临时文件替换保证原子写入。资源 ID 比较不区分大小写，避免编辑、绑定和删除出现大小写不一致。
