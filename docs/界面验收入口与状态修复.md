# 界面验收入口与状态修复

日期：2026-11-03。

## 本轮修改

- 控件预览验收改为实际使用“系统设置 → 日志与诊断 → 控件预览”的入口，通过页面导航、分类选择和按钮调用共享 ShellNavigationService；不反射调用主窗口私有页面切换方法。
- NavigationSmokeHelper 在选择前核对当前导航目录，不存在的路由明确报错，避免把未发生的导航算作通过。
- 主窗口 UI 验收移除已退役的协议库、自定义协议、DBC 和协议测试页面交互，改为明确验证它们不在导航中、ProtocolHost 为空且折叠。协议模型检查代码保留于 ProtocolRegression，本轮没有运行该独立范围。
- 工具栏范围检查使用当前工作台、手动测试、设备、硬件配置、插件和设置路由，并确认页面实际切换。
- 新增 --ui-preview，单独检查控件预览、六种主题/强调色组合、绑定、弹窗及无工程访问；保留 --ui-documents 进行文档短验收。
- 文档验收读取现有序列子工程工作区，而非旧版散列序列文件。序列之间切换校验“保留内存修改、非法输入阻止切换、明确保存后持久化”；工程切换和关闭继续验证保存、放弃、取消及清理保护。
- 文档运行验收等待 OpenTAP 实际进入步骤和暂停确认，再执行关闭操作，避免把跨进程操作当作同步调用。
- 设置文件使用临时路径；这组 shell/文档验收的站变量保存在测试服务内存中，不向用户站变量文件写入测试数据。

## 修复的实际缺陷

### 首次主题加载覆盖项目主题并重复皮肤

ThemeService 原先先计算主题与皮肤索引，插入首次项目主题后仍使用原皮肤索引替换条目。插入使索引偏移，项目主题被皮肤覆盖，下一次切换又留下旧皮肤。

现在先完成已知索引的替换，再插入缺失的主题。验收同时检查首次加载及每次切换后恰好有一个项目主题和一个匹配当前明暗模式的皮肤，并检查按钮样式及资源字典数量不变。没有修改 IndustrialKit 源码或复制控件模板。

颜色弹窗输入框的旧断言使用 SurfaceBrush；当前公共输入样式使用独立的 InputBackgroundBrush。断言已跟随真实样式契约，分别检查打开后的浅色状态和切换后的深色状态。该项属于验收断言修正。

### 已有站变量造成工程刚打开就显示未保存

MainViewModel.LoadWorkspace 加载站变量后没有同步 _stationBaseline，导致非空站变量与构造阶段的空基线比较，工程一打开就被判定为修改。

现在与序列工作区基线一起记录已加载站变量的基线。文档 UI 验收固定带有非空站变量，检查初始未修改、撤销回到保存状态以及切换工程后重新建立正确基线。
