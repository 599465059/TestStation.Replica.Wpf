# 纯软件序列编辑与执行

本阶段使用工程内的模拟通道，由自己的 WPF 编辑器编辑序列，由独立 OpenTAP Host 执行。没有接入硬件。

现已完成编译及实际 WPF + OpenTAP 验收。可运行的全功能示例位于 `examples/自动测试全功能验收`，验收范围与结果见 `docs/自动测试全功能验收记录.md`。

## 软件工程、序列子工程与标签页

软件工程仍是最外层容器，自动测试是其中一个模块，不会把手动测试等内容划入某个序列标签页。

- 自动测试中每个标签页代表一个序列子工程；可新建、重命名和删除标签页。
- 新建子工程默认创建一个主序列。序列列表中，蓝色 ▶ 标识主序列，绿色 ↳ 标识子序列，同时显示文字类型。
- 序列列表右键可新建子序列、重命名、复制、删除、运行。每个序列子工程固定只有一个主序列，主序列不能删除；新建的其他序列全部是子序列，被调用的子序列需要先解除调用才能删除。
- 主序列可以调用子序列，子序列也可以调用子序列。主序列不能成为调用目标，循环调用仍会被拒绝。
- 选中主序列时，入口为“运行主序列”，运行结果写入正式报告；选中子序列时，入口为“调试子序列”，只显示本次实时结果，不保存 HTML、JSON 报告或运行历史。
- 主序列内部调用子序列时，子序列结果仍按步骤的“记录执行结果”设置汇入主序列报告。
- 切换标签页和序列会提交有效的属性输入并保留尚未保存的修改；输入无效时阻止切换。保存工程会保存全部标签页。切换软件工程或退出时统一处理未保存内容。
- 当前同时执行一次运行；运行期间不能手动切换、修改或删除标签页和序列，执行页面会自动跟随正在运行的序列。

跨标签页复制：右键子序列，选择“复制子序列及依赖”，切换目标标签页，再选择“粘贴子序列及依赖”。粘贴生成新的序列和步骤 ID，重新关联内部调用，不关联回原标签页。本版同时携带来源标签页的全局变量定义；同名定义的类型或默认值冲突时，阻止粘贴并提示处理，不覆盖目标定义。

## 变量作用域与右键菜单

变量面板使用图标、颜色及文字共同区分作用域：

| 标识 | 类型 | 可见范围 | 引用示例 |
| --- | --- | --- | --- |
| 蓝色 ● | 局部 | 当前序列本次调用 | `${Locals.count}`，兼容 `${count}` |
| 绿色 ◆ | 全局 | 当前序列子工程，即本标签页内所有序列 | `${Globals.count}` |
| 金色 ★ | 站变量 | 当前软件会话内所有标签页与软件工程 | `${Station.count}` |
| 紫色 → | 运行参数 | 当前序列本次调用，通过运行窗口或调用参数传入 | `${limit}` |

局部变量每次调用重新初始化，子序列看不到调用者的局部变量。运行参数是局部数据的一种，保留原有参数输入功能。不同作用域允许同名，使用明确前缀避免混淆。

右键变量行可以重命名、删除，也可以直接新建指定作用域的变量或运行参数。右键先选中目标行；空白处菜单只允许新建，避免操作之前选中的变量。新建后可直接在下方修改名称、类型、默认值，再点“应用”。名称必须是标识符，同一作用域内不能重名。重命名或删除定义后，需要相应调整步骤中的名称引用以及子序列调用参数名称。

STATEMENT 的目标变量可填写 `Locals.count`、`Globals.count` 或 `Station.count`，表达式可填写 `Globals.count + 1`。WAIT、循环、条件、调用参数、设置值和断言中的表达式同样支持这些前缀。

全局和站变量的运行值在本次软件会话内延续，修改默认值、类型或名称会清除相应运行值；局部变量每次调用使用默认值。全局运行值按标签页隔离，重新打开软件工程后重新初始化；站变量运行值跨软件工程延续，关闭软件后重新初始化。保存的是变量定义与默认值，不会把每次运行值自动写回默认值。共享变量定义的编辑不进入单个序列的撤销栈。

序列子工程及全局定义保存到 `sequences/workspace.json`；站变量定义保存到当前用户的 `%LOCALAPPDATA%/TestStation/station-variables.json`。旧工程第一次打开时在内存中迁移到默认序列子工程，保存后使用新工作区文件；原有 `sequences/*.tsseq` 保留，不再作为新工作区的权威数据。

## 运行参数

在变量面板中选择“运行参数（局部）”，或右键“新建运行参数”，选择文本、整数、数字或布尔类型。默认值可以留空；没有默认值的参数在运行前必须填写。文本参数允许填写空字符串。

## 表达式、信号表和数组判定

步骤属性中可以展开“执行前 / 执行后表达式”。每行写一条赋值，例如：

```text
Locals.limit = clamp(Globals.raw * 1.05, 0, 10)
Station.total = Station.total + 1
```

公式支持加减乘除、取模、比较、逻辑运算、括号、数组字面量和从 0 开始的下标，以及 `abs`、`sqrt`、`pow`、`round`、`floor`、`ceil`、`min`、`max`、`sum`、`avg`、`length`、`clamp` 等函数。数学常量使用 `Math.PI`、`Math.E`。表达式校验会检查语法、赋值目标和变量/通道引用；运行时继续检查实际类型、数组长度和结果范围。执行前表达式在前置条件通过后、步骤主体前运行；主体执行后即使判定失败，也会执行后表达式，取消和跳过时不执行。表达式出错使步骤判为 Error，并遵循失败动作设置。

SET VALUE 和 GET VALUE 在“步骤专属”页使用控件库样式的信号读写表。新建步骤默认零行；可添加空行，在第一列的下拉框选择通道，或点击“批量添加通道”，在窗口中搜索并勾选多个通道后生成多行。已有通道显示“已添加”，批量操作不重复添加；行内和工具栏都可以删除行。列宽允许拖动调整，空间不足时在表格内部横向滚动。

数据类型列只读，由所选通道定义自动带出；不通过修改当前数值切换类型。当前模拟通道定义与初始值分别保存在 `channels/simulation.json` 的 `definitions` 和 `values` 中。旧文件没有定义时兼容生成初始定义，保存模拟数据后固定。预留的 `ISequenceChannelProvider` 接口允许后续插件提供通道 ID、数据类型、来源和读写权限；目前没有接入硬件插件或自动安装插件的机制。

写入值和接收变量保持空白，不自动复制当前通道值。空表可以应用、保存及切换步骤，校验或运行时会提示至少选择一个通道。输入方式为常量时，数组使用 JSON 形式，例如 `[1, 2, 3]`；输入方式为变量 / 公式时可填写 `Locals.value * 2` 或 `[Globals.a, Globals.b]`。GET VALUE 的数值列填写接收变量名，可留空只读取通道；读取行的输入方式用于比较期望值。

GET VALUE 每一行可以选择比较方式：相等、不等、大小关系、范围内、范围外、绝对容差、相对容差、包含文本或正则匹配。数组规则支持全部元素满足、任一元素满足、同长度逐项满足。空数组直接判定失败；逐项比较时长度不同判定失败。比较不通过会使该步骤 Fail，并遵循步骤的 STOP、CONTINUE 或 GOTO_CLEANUP 设置。

当前没有硬件插件，模拟数据中提供 `Sim.Voltage`、`Sim.Current`、`Sim.Temperature`、`Sim.Enabled`、`Sim.SerialNumber` 和 `Sim.Samples` 示例通道。也可以点击模拟数据面板的“添加示例模拟通道”，再按需要修改或删除。

“校验公式与变量”会校验当前步骤的前后表达式、前置条件、步骤字段、信号表和调用参数；变量面板的“校验”会校验当前变量名称、作用域、类型和默认值。校验通过只代表静态内容有效，运行中的通道值和公式结果仍可能导致步骤失败。

一个不接硬件的配置示例：先声明数字局部变量 `limit`、`reading`（默认值均为 `0`），数字数组局部变量 `samples`（默认值 `[]`），数字全局变量 `average`（默认值 `0`）。然后配置以下步骤：

1. SET VALUE：执行前填写 `Locals.limit = 5 * 1.05`；添加 `Sim.Voltage` 行，数据类型为数字，输入方式选择“变量 / 公式”，第三列填 `Locals.limit - 0.2`。
2. GET VALUE：选择 `Sim.Voltage`，数据类型为数字，接收变量填 `Locals.reading`；比较选择范围内，输入方式为常量，下限 `4.5`，上限 `5.5`。
3. GET VALUE：选择 `Sim.Samples`，数据类型为数字数组，接收变量填 `Locals.samples`；比较选择 `==`，数组规则选择“同长度逐项满足”，输入方式为常量，期望值 `[4.8, 4.9, 5.0]`；执行后填写 `Globals.average = avg(Locals.samples)`。

数组比较按顺序对应元素，`ALL` / `ANY` 中的标量期望值会应用于各元素。选择 `!=` 时同样逐元素判断，再按全部/任一规则汇总；如果需要判断“两个完整数组不相同”，可使用条件公式 `Locals.samples != [4.8, 4.9, 5.0]`。文本包含和正则区分大小写。相对容差以期望值绝对值的百分比计算。

这些界面和规则通过本软件的 OpenTAP 适配步骤实现；序列调度、步骤执行、判定和结果事件仍交给 OpenTAP。后续硬件插件接入时，可将模拟通道读写替换为插件接口调用。

点击运行或调试时，有参数的序列会打开输入窗口。每个参数可以选择使用默认值或填写本次常量。整数与数字使用英文小数点；布尔值使用 true/false（也接受 1/0）。输入不符合类型时显示错误，取消输入不会启动 Host。本次输入不修改序列默认值。

## 子序列调用

先创建目标子序列，并声明它的参数。回到主序列，插入“序列调用”，在属性区下拉选择目标。参数会按目标序列的声明显示：

- 使用默认值：调用时不传该字段，由子序列自己的默认值初始化。
- 常量：按目标参数类型保存，例如数字 5、布尔 true、文本 SN001。
- 变量引用：例如 `${limit}`、`${i}` 或 `${limit + 1}`，运行到调用步骤时取值。

引用建议包含主序列变量、FOR 循环变量及当前模拟通道。循环变量只有在对应循环内才有效。被调用序列使用独立变量作用域；参数传入后不会自动回写主序列。模拟通道由整次运行共享。

原有 JSON 中已失效、重复或不合法的调用参数会提示错误。重新选择目标并配置参数可以替换原配置。调用递归、目标不存在、缺少必填参数、常量类型不匹配会在运行前提示；依赖运行数据的引用值在执行时校验。

## 一个编辑示例

1. 在模拟数据中建立通道 `voltage`，值填写 `4.8`。
2. 创建子序列“电压检查”，声明数字参数 `limit`，默认值 `5`。
3. 在子序列 Main 中添加 GET VALUE，通道填写 `voltage`；添加 ASSERT，通道填写 `voltage`，比较方式选 `<=`，期望值填写 `${limit}`。
4. 创建主序列，声明数字参数 `limit`（默认 5）和整数参数 `delay_ms`（默认 100）。
5. 在主序列添加 WAIT，时间填写 `delay_ms`；添加 FOR，变量填写 `i`，起始 1，结束 3，步长 1，最大次数 1000。
6. 在 FOR 内添加序列调用，目标选择“电压检查”，其 `limit` 选择变量引用并填写 `${limit}`。
7. 保存工程。以后运行时可在参数窗口覆盖 limit，并在步骤表状态列查看完成、未完成、通过和失败。

WAIT 和循环数值字段支持表达式，例如 `delay_ms`、`${delay_ms}`、`delay_ms + 50`。数值结果必须是整数；WAIT 不接受负数，FOR 步长不能为 0，最大循环次数必须大于 0。数字范围、变量是否存在等依赖运行值的约束由 Host 执行时检查。

独立 ASSERT 的期望值支持 JSON 标量、一维数组或变量引用：`5` 是数字，`true` 是布尔值，`"true"` 是文本，`[1, 2, 3]` 是数组，`${limit}` 是引用，`""` 是空文本。SET VALUE 使用表格中明确选择的数据类型和输入方式，文本常量直接填写内容即可。ASSERT 的失败行为统一由步骤公共属性“失败动作”控制。

## 步骤属性导航与状态

步骤属性面板采用底部属性区内的导航页，减少长表单拥挤：

- “通用属性”：步骤 ID、名称、说明、超时、前置条件和是否记录结果，适用于所有步骤。
- “执行与判定”：执行前/后表达式、结果动作和失败信息。带判定的步骤显示失败动作；普通步骤显示完成后的动作说明。
- “步骤专属”：IF/FOR/WHILE 等控制字段、SET/GET VALUE 信号读写表以及子序列调用参数。
- “高级参数”：未被步骤类型识别的扩展 JSON 参数。

步骤表状态会按步骤是否包含判定区分：带判定的 ASSERT 或带比较规则的读取步骤显示“通过 / 失败”；普通步骤显示“完成 / 未完成”。通过使用绿色、失败使用红色、完成使用蓝色、未完成使用橙色，运行中的步骤使用紫色。空白或尚未执行的步骤显示为未完成。

执行进入子序列时，序列列表和步骤表自动切换到对应子序列，展开步骤并滚动到当前高亮行；子序列继续调用子序列时同样跟随。返回调用者后切回调用者的当前步骤，各序列已经执行的步骤状态保留。暂停期间保留当前页面和步骤高亮；运行结束或停止后返回本次运行入口并清除当前步骤高亮。自动切换页面不会改变主序列正式报告或子序列调试不生成报告的规则。

- 步骤结果：显示每次实际执行的序列、区域、状态、耗时和消息。选中记录可查看调用路径及实际执行标识，循环重复执行保留多条结果。
- 变量与通道：运行时显示当前子序列变量、已读通道、模拟通道；顶部显示调用层级和所在循环次数。运行结束显示最终值。
- 结果表：模拟 SET VALUE、GET VALUE、ASSERT 通过 OpenTAP 结果系统发布数据，显示实际值、期望值与判定。
- 历史报告：选择工程已有记录后，切换到“步骤结果”查看详情，也可打开 HTML 报告。运行中禁止切换历史记录。

暂停为协作式暂停；收到 Host 确认后界面才显示已暂停。暂停不计入 WAIT 时长或步骤超时。停止时若 Host 超过 5 秒仍未退出，会结束其进程树。强制终止时报告保留已收到的结果，但不能保证未完成步骤的结果完整。

取消“记录执行结果”的步骤仍更新实时状态和变量，但不会进入步骤报告或发布结果表。

## 模拟场景

在模拟数据页签填写场景名称，点击“保存当前数据”。可以分别保存“正常”“超限”“缺失值”等场景。同名保存会更新已有场景。

选择场景后，点击“载入”才会切换当前通道数据。载入时替换整个模拟数据集合，因此“缺失值”场景可以省略某个通道。删除场景只删除已命名的快照，保留当前通道数据。

执行器使用本次运行开始时的数据快照。运行中的 SET VALUE 只修改本次模拟数据，不修改工程文件或已保存场景。修改单个模拟通道后，界面会标记“当前模拟数据（已修改）”；需要时再次保存场景。

工程文件位置：

- `channels/simulation.json`：当前模拟通道配置。
- `channels/simulation-scenarios.json`：已命名场景。
- `reports/*.tsrun.json`：统一运行结果，包含参数、初始/最终模拟值及步骤结果。
- `reports/*.opentap.json`：OpenTAP 原始事件，包含调用、循环快照、结果表与步骤执行标识。
- `reports/*.html`：可独立打开的报告，包含序列和调用路径。
