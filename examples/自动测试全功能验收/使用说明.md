# 自动测试全功能验收工程

双击 `打开验收工程.cmd`。脚本仅补充本示例使用的 9 个 `AT_` 站变量，保留已有变量和同名变量的默认值；发生类型冲突时停止并提示。首次补充前备份原站变量文件。软件已启动时请重新打开软件，以载入新增的站变量定义。

进入“自动测试”，选择第一个标签页的 `01 全功能主序列（约65秒）` 并运行。8 个运行参数均有默认值，可直接确认。序列包含 13 次 5000 毫秒等待，整体约 66 秒；正常结果为通过。正式运行生成的 HTML、结果 JSON 和 OpenTAP 事件保存在 `reports` 中。

## 标签页和入口

| 标签页 | 入口 | 预期结果 |
| --- | --- | --- |
| 01 正常功能与65秒运行 | 01 全功能主序列 | 通过；运行超过1分钟 |
| 01 正常功能与65秒运行 | 02 同标签页共享值复核 | 子序列调试入口；先运行全功能主序列，再调试此入口；通过且不生成报告 |
| 01 正常功能与65秒运行 | 子序列A、子序列B | 可单独调试；通过；不生成报表 |
| 02 隔离、异常与控制测试 | 01 标签页隔离与站共享 | 子序列调试入口；先运行全功能主序列；通过且不生成报告 |
| 02 隔离、异常与控制测试 | 预期FAIL开头的入口 | 子序列调试入口；故意提供不满足的比较值或超时；正确结果就是失败 |
| 02 隔离、异常与控制测试 | 预期ERROR · 除零 | 子序列调试入口；故意计算1/0；整体失败并保留错误原因 |
| 02 隔离、异常与控制测试 | 取消与暂停 | 子序列调试入口；等待30秒；可暂停、继续、停止；停止后显示已停止 |
| 02 隔离、异常与控制测试 | 必填运行参数 | 子序列调试入口；参数填42时通过；取消参数窗口则不启动运行 |

全局变量按标签页隔离，站变量在软件会话内共享。为了方便对照，三种作用域使用同名 `AT_Number` 等定义；步骤中总是明确填写 `Locals.`、`Globals.`、`Station.`。运行参数命名为 `P_`。关闭并重开工程会重置标签页全局运行值；站变量运行值在关闭软件后重置。

## 正常主序列覆盖

- 14种步骤：INITIALIZE、SET VALUE、GET VALUE、WAIT、ASSERT、IF、FOR、WHILE、BREAK、CONTINUE、STATEMENT、SEQUENCE CALL、LOG、COMMENT，以及初始化/主体/清理区域；FOR内部标识为loop。
- 局部、标签页全局、站变量、运行参数，各覆盖数字、整数、布尔、文本及对应一维数组，共32种作用域/类型组合；另有循环变量。
- 多行信号写入和读取、接收变量、常量和公式、数组逐项比较、全部/任一元素规则、标量广播、范围、绝对/相对容差、文本包含和正则。
- 数学函数、数组下标、科学计数法、逻辑条件、执行前后表达式、变量引用和参数传递。
- 正/负步长FOR、WHILE、嵌套IF中的BREAK/CONTINUE；主→子A→子B调用；局部隔离和共享值传递。
- 前置条件跳过、禁用步骤、关闭结果记录、四种日志级别、步骤说明、自定义失败消息和超时。

实际测试记录和重复验收命令见源码工程 `docs/自动测试全功能验收记录.md`。当前示例使用模拟通道，不依赖硬件插件；动作库尚未列入已实现功能。
