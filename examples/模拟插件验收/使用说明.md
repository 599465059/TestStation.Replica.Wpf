# 公共 SCPI 虚拟电源验收工程

先在项目根目录运行 `启动虚拟电源.cmd`，保持窗口运行。它会在 `127.0.0.1:5025` 提供独立的公共 SCPI 虚拟电源；再打开 `project.json` 所在目录，进入“自动测试”，选择“插件通道自动测试主序列”。

主序列会通过真实 TCP SCPI 设置电源电压、电流和输出，读取电源测量值，然后执行范围判定、等待 3 秒观察当前步骤高亮。OpenTAP Host 的电源读写请求会回到主程序的统一设备服务；手动面板与自动步骤访问同一台虚拟电源。

“插件读取子序列”可以单独运行；预期通过且不生成报表。

进入“手动测试”后，三个家族插件界面直接显示在同一层工作区。顶部工具栏可切换标签／窗口视图，以及平铺、层叠；关闭界面后可通过“添加设备界面”重新打开。

可见的设备界面每 500 ms 轮询测量通道；切换到其他页面或隐藏设备标签后停止该界面的订阅。自动测试运行时暂停手动轮询和操作；读取按钮仍支持单次读取。

左侧导航的“手动测试”“自动测试”“设备测试”为一级入口。“设备测试”展开后包含设备管理和各设备家族；每个家族直接打开自己的紧凑测试面板，无额外标签或说明栏。

电源面板使用“公共 SCPI 电源（TCP）”配置，顶部可以填写主机和端口并连接。当前支持 `*IDN?`、`*RST`、`*CLS`、`SYST:ERR?`、电压/电流设定、输出控制和测量查询等公共指令；尚未声明为某个实际 ITECH 型号。

同一家族的设备测试面板、手动面板和自动步骤可选通道共享当前型号。切换型号会隐藏不支持的控件、停止相关轮询，并限制读写接口；已有序列引用不支持的通道时，运行前提示。型号选择当前保存在本次软件会话中，重新启动恢复 S 型。

“设备测试 → 设备管理”可启用、禁用内置设备家族，启用状态保存到本机。禁用后移除相关界面和可选通道；自动测试运行期间禁止更改设备状态或型号。当前尚不包含外部插件包安装及程序集卸载。
